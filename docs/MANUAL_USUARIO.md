# Manual de Usuario - Aplicación DogCare

## 1. Primeros Pasos e Inicio de Sesión
1. **Acceso:** Inicia sesión con Google o crea una cuenta con tu correo electrónico y contraseña en la pantalla de bienvenida.
2. **Mi Perfil:** Accede a la pestaña *Perfil* para completar tus datos de contacto y dirección de entrega por defecto.

## 2. Mis Perros y Calculadora de Edad Canina
1. **Registrar Perro:** Pulsa el botón `+` en la pantalla *Mis Perros* para registrar el nombre, raza, edad, sexo, peso y categoría de tamaño de tu perro.
2. **Equivalencia de Edad:** Consulta el cálculo aproximado de edad humana y etapa de vida (Cachorro, Adulto, Senior).

## 3. Asistente con IA (Gemini)
1. **Consultas General:** Realiza preguntas sobre nutrición, higiene y bienestar.
2. **Selección de Mascota:** Selecciona uno de tus perros registrados para contextualizar las respuestas con sus datos de peso y raza.
3. **Tarjeta de Urgencia Veterinarias:** Si la consulta detecta síntomas de alerta (convulsiones, dificultad respiratoria, sangrado), el sistema muestra una tarjeta destacada con botón directo a llamadas de urgencia y búsqueda en mapa.

## 4. Búsqueda de Veterinarias (OpenStreetMap)
1. **Geolocalización o Búsqueda por Ciudad:** Concede el permiso de ubicación o escribe el nombre de una ciudad (ej. *Bogotá*, *Medellín*) para centrar el mapa.
2. **Mapa Interactivo:** Toca los marcadores para ver el nombre, dirección real registrada en OSM y teléfono de la veterinaria.

## 5. Marketplace de Alimentos y Carrito
1. **Explorar Alimentos:** Filtra por categorías (*Concentrado seco*, *Alimento húmedo*, *Snacks*) o etapa de vida.
2. **Carrito Persistente:** Agrega productos. El carrito se guarda automáticamente en la nube.
3. **Checkout:** Realiza el pedido. El sistema valida el stock antes de aprobar la transacción.
